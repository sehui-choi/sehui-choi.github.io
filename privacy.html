Privacy Policy

Last updated: 2026-10-22

"kodwasip workspace tools" is a private tool used only by its owner (Instagram @kodwasip, kodwasip@gmail.com). No other users can sign in.

Data accessed

With the owner's consent through Google OAuth, the tool accesses the owner's own Gmail, Google Calendar, Google Sheets and Google Drive.

How data is used

  • Gmail: to identify brand collaboration emails and extract fields such as dates and agreed fees.
  • Sheets / Drive: to store those fields in a spreadsheet owned by the owner.
  • Calendar: to create deadline reminders in the owner's own calendar.

Sharing

Data is not sold, shared with, or disclosed to any third party. It is processed on the owner's own computer and stored only in the owner's own Google account.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
